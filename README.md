# ★ הכוכבים שלי

ממשק עברי חדש לאתר הכוכבים של מולטיפאס ([idf.mltp.co.il](https://idf.mltp.co.il)): יתרות, תנועות ורשתות עם חיפוש, ושמירת הקוד האישי מה-SMS.

## התקנה מהירה

1. מתקינים תוסף סקריפטים: [Tampermonkey](https://www.tampermonkey.net/) או [Violentmonkey](https://violentmonkey.github.io/) (באנדרואיד דרך Firefox, באייפון אפליקציית Userscripts).
2. **[לחצו כאן להתקנה](https://raw.githubusercontent.com/lidanthedev/idf-stars/main/idf-stars.user.js)** ומאשרים בתוסף.
3. נכנסים כרגיל ל-[idf.mltp.co.il](https://idf.mltp.co.il/Account/Login), והממשק החדש עולה אחרי הכניסה.

דף התקנה: https://lidanthedev.github.io/idf-stars/

## מה יש בפנים

- מסך כניסה חדש ונקי (אותו טופס ואותו reCAPTCHA של האתר, Enter שולח)
- סך הכול זמין, בחלוקה לכוכבים ולארנקי רשתות
- **הקוד שלי**: מדביקים את כל הודעת ה-SMS והקוד נשלף אוטומטית. אפשר לערוך ולהעתיק, ולבקש שליחה חוזרת ב-SMS
- חיפוש אחד לכל הלשוניות: יתרות, תנועות (סינון לפי תקופה וסוג פעולה) ורשתות (הנחה וחיוג בלחיצה)
- מצב כהה אוטומטי, מותאם לנייד

## פרטיות

- הסקריפט רץ רק בתוך האתר המקורי אחרי שנכנסתם בעצמכם (כולל ה-reCAPTCHA). הוא לא שולח נתונים לשום מקום אחר.
- הקוד נשמר רק בדפדפן שלכם (localStorage), ללא הצפנה.
- להצגת האתר המקורי מוסיפים `?orig=1` לכתובת.

ממשק לא רשמי, ללא קשר למולטיפאס או לצה"ל.
